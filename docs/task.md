# Библиотечный каталог - Backend API

## Задание 1: Создание базового бэкенд-приложения для библиотеки

Настройте начальный проект для разработки API библиотечного каталога:

### Структура проекта

Создайте новый проект в PyCharm или VSCode со следующей структурой:

- Папка `/src/library_catalog`
- Файл `main.py` внутри этой папки для FastAPI приложения
- Файл `models.py` для описания структуры данных

### Установка и запуск

1. Создайте и активируйте виртуальное окружение Python

2. Создайте файл `requirements.txt` с зависимостями:

   ```txt
   fastapi
   uvicorn[standard]
   pydantic
   ```

3. Установите зависимости через `pip install -r requirements.txt`

4. Запустите минимальное FastAPI приложение командой:

   ```bash
   uvicorn src.library_catalog.main:app --reload
   ```

5. Проверьте доступность API по адресу <http://127.0.0.1:8000/docs>

## Задание 2: Разработка API для управления книжной коллекцией

Расширьте проект, добавив функциональность для работы с книгами:

### Эндпоинты

Реализуйте эндпоинты для основных операций:

- `get_books`: получение списка всех книг с возможностью фильтрации
- `get_book`: получение информации о конкретной книге
- `add_book`: добавление новой книги в каталог
- `update_book`: обновление информации о книге
- `delete_book`: удаление книги из каталога

### Модель данных книги

Каждая книга должна содержать следующие данные:

- `id` (уникальный идентификатор)
- название
- автор
- год издания
- жанр
- количество страниц
- доступность (в наличии/выдана)

### Подзадачи

- Создайте файл `readme.md` и опишите проблемы хранения данных в оперативной памяти
- Реализуйте хранение данных о книгах в JSON-файле
- Проанализируйте преимущества и недостатки файлового хранения
- Создайте класс `BookRepository` для работы с хранилищем (PostgreSQL)
- Добавьте в readme сравнительный анализ разных способов хранения данных (оперативная память, файлы, базы данных)
- Интегрируйте ваше приложение с внешним сервисом для хранения данных (например, jsonbin.io)
- Изучите вопрос конкурентного доступа к данным и опишите потенциальные проблемы
